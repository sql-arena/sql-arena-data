# Datasets Available

These are the datasets that can be generated by this repo:

| Dataset | Licence |
|---|---|
| [Join Order Benchmark](./job/README.md) | IMDb data snapshot; IMDb's terms limit its data to personal, non-commercial use. The query repo has no licence file |
| [TPC-H SF1 and SF1000](./tpch/README.md) | TPC EULA for the benchmark; generated with the MIT-licensed DuckDB `tpch` extension |
| [TPC-DS SF1](./tpcds/README.md) | TPC EULA for the benchmark; generated with the MIT-licensed DuckDB `tpcds` extension |
| [NYC Taxi](./nyctaxi/README.md) | NYC TLC public trip records, under the NYC Open Data terms of use |
| [Public BI Benchmark](./publicbi/README.md) | Repository code MIT; the data comes from public Tableau Public workbooks and has no explicit licence |
| [Telecom Italia Big Data Challenge](./telecomitalia/README.md) | ODbL 1.0, attribution required; derived data must stay under ODbL |

Iceberg metadata over these datasets is described in [iceberg/README.md](./iceberg/README.md).
